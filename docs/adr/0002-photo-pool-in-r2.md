# Photos are copied into Cloudflare R2, knowing Google's policy

Google Places photos and Instagram photos are downloaded, resized and stored in an R2 bucket per Place, and configs reference those URLs. Google's Places policy forbids caching any Places content except place IDs, and Instagram photos belong to the restaurant; the operator accepted both risks on 2026-09-12 because a Demo with expired or broken images loses the sale outright, Places URLs embed the API key, and the same config must build identically on any device. Mitigations: Demos are shown in person and not published, Google attribution is displayed until the owner's own photos replace the pool, and a declined Place's photos can be deleted. If enforcement ever becomes real, the fallback is item-level fetching at build time with no storage, which the reference layout already allows.
