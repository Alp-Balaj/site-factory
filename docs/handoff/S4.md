## What landed

- `factory/lib/copy-checks.mjs`: `checkCopy(config)` → `[copy-dash, copy-language]`, pure. `theme.*` and `meta.*` are
  not copy (theme.note is an English note with dashes in it) and are skipped by the dash check. The language check
  reads hero, about, tagline and every item's name and desc as separate units; a unit fails at more than two whole-word
  hits of `the, and, with, our, i, je, sa`, or any Cyrillic. Because `i`, `je`, `sa` are everyday Albanian words
  ("ushqim i mirë", "ti je", "sa herë"), those three count only in a unit with no `ë`/`ç`; Serbian never carries
  those letters. Without that rule every real config failed on `i`.
- `factory/lib/qa/hard.mjs`: one exported function per check plus `runHard(slug)`; fixtures under
  `factory/lib/qa/fixtures/`. Image check is HEAD then GET with redirects followed: Google's photo media endpoint
  answers HEAD with 404 and GET with 302, so the fallback is load-bearing. Hero overflow at 390 px looks for
  `header.hero, .hero, header, [data-hero]` and reports every visible element wider than the viewport and any `h1` /
  `.headline` whose text range leaves its box.
- `factory/lib/qa/soft.mjs`: `runSoft(slug)` sends both previews (base64 PNG) to `claude-sonnet-4-6` through the
  claude-agent-sdk with a JSON schema keyed by the five check ids; `parseSoft` clamps scores to 1–5. Takes about 30 s.
- `factory/jobs/qa.mjs`, registered as `qa`; `npm run qa -- <slug> [--no-vision] [--build]` (package.json, one line).
  Builds when `build/index.html` is missing or older than `config.json` (calls `build()` directly: enqueueing through
  the one-worker queue from inside a job would wait on itself). A build error becomes the `build` hard failure with
  astro's message, so the Place still lands in `qa_failed` with a reason instead of the job crashing.
- Status: `generating → qa_passed | qa_failed`. A rerun from `qa_passed` / `qa_failed` / `ready` goes through
  `generating` ("qa rerun") when the result changes; from `shown` onwards the status stays and only `state.qa` updates.
